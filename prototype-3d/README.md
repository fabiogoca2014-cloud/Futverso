# Futverso 3D

Protótipo independente de futebol 3D em navegador, com Three.js, para celulares e computadores.

Controles: joystick ou WASD/setas; passe (J), chute (K), trocar (L).

Execute via servidor HTTP ou GitHub Pages. Requer internet para carregar a biblioteca Three.js pelo CDN.

Escopo: jogo arcade experimental, não equivalente a Football League. Ainda não validado em Android real.
